# Projeto-Estrutura-de-Dados 
Repositório para desenvolvimento do projeto de implemento das seguintes Estruturas de Dados:
- **Lineares:** Lista encadeada simples, Lista encadeada dupla, Fila simples (queue), Fila dupla (deque);
- **Estruturas Hierárquicas:** Árvores Binárias de Busca e Sistema Gerenciador de Banco de Dados – SBD;
- **Hash e Grafos:** Tabela Hash e Deduplicação, Grafos, Díígrafos, Multigrafos e Hipergrafos;
- **Ordenação:** Ordenação Externa por MergeSort
